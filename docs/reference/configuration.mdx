# Configuration

This page documents configuration values that are read by the current source. Older examples that mention Redis, HOST, or ALLOW_LOCAL_ONLY are not current server options.

## Server environment variables

| Variable | Default | Behavior |
| --- | --- | --- |
| PORT | 3000 | HTTP and WebSocket server port. |
| DEBUG_MODE | false | Enables diagnostic logs, including peer IP details. Keep disabled in production. |
| WS_FALLBACK | enabled unless set to false | Enables server-relayed WebSocket file/message fallback. Set WS_FALLBACK=false to disable it. |
| WS_ALLOWED_ORIGINS | empty | Comma-separated HTTP(S) origins allowed to open browser WebSocket connections. When empty, the server compares the Origin host to the request Host. Native clients may omit Origin. |
| RTC_CONFIG | built-in Google STUN list | Path to a JSON file containing sdpSemantics and iceServers. Its TURN username/credential values are sent to clients; use short-lived TURN credentials and quotas. |
| SIGNALING_SERVER | disabled | Alternate signaling host without a protocol prefix. Cannot be combined with RTC_CONFIG, active WS_FALLBACK, or IPV6_LOCALIZE. |
| IPV6_LOCALIZE | disabled | Integer from 1 to 7 controlling how many IPv6 segments are used for peer grouping. |
| RATE_LIMIT | disabled | Enables Express HTTP rate limiting. true selects 5 trusted proxy hops; an integer sets the trusted proxy hop count. The limiter allows 1,000 HTTP requests per IP per 5 minutes. |
| DONATION_BUTTON_* | unset | Controls the optional donation button. |
| TWITTER_BUTTON_* | unset | Controls the optional Twitter/X button. |
| MASTODON_BUTTON_* | unset | Controls the optional Mastodon button. |
| BLUESKY_BUTTON_* | unset | Controls the optional Bluesky button. |
| CUSTOM_BUTTON_* | unset | Controls the optional custom button. |
| PRIVACYPOLICY_BUTTON_* | unset | Controls the optional privacy-policy button. |

## Important defaults

- WS_FALLBACK is enabled by default. Disable it explicitly if the server must not relay file payloads.
- RATE_LIMIT affects HTTP requests only. WebSocket upgrades use a separate server event and do not pass through Express rate-limit middleware.
- The RATE_LIMIT integer is also used as the reverse-proxy trust hop count. Configure it for the actual proxy chain; an incorrect value can cause all clients to appear under the proxy IP or can trust an untrusted forwarding hop.
- DEBUG_MODE=true can reveal peer IP and diagnostic information in logs. Do not enable it in production.

## Command-line flags

| Flag | Behavior |
| --- | --- |
| --rate-limit | Enables HTTP rate limiting with 5 trusted proxy hops. |
| --auto-restart | Enables automatic process restart behavior for uncaught exceptions. |
| --localhost-only | Binds the HTTP server to 127.0.0.1 and restricts the WebSocket peer IP to local addresses. |
| --include-ws-fallback | Forces WebSocket fallback on. |

## Example: Render

The repository's Render blueprint uses Docker. The current security hardening PR proposes RATE_LIMIT=5; verify the deployed environment after that change is merged and deployed.

    envVars:
      - key: NODE_ENV
        value: production
      - key: PORT
        value: "3000"
      - key: RATE_LIMIT
        value: "5"
      - key: ONION_PRIVATE_KEY_BASE64
        sync: false

## Example: self-hosted Node.js

    NODE_ENV=production PORT=3000 RATE_LIMIT=5 WS_FALLBACK=false npm start

On Windows PowerShell:

    $env:NODE_ENV = "production"
    $env:PORT = "3000"
    $env:RATE_LIMIT = "5"
    $env:WS_FALLBACK = "false"
    npm start

## WebSocket and TURN configuration

A custom RTC_CONFIG file must be valid JSON:

    {
      "sdpSemantics": "unified-plan",
      "iceServers": [
        { "urls": "stun:stun.example.com:3478" },
        {
          "urls": "turns:turn.example.com:5349",
          "username": "short-lived-username",
          "credential": "short-lived-credential"
        }
      ]
    }

The configuration is sent to connected clients. Never place long-lived TURN credentials in a public repository or assume client-delivered credentials remain private.

## Variables not read by the current server

The current server/index.js does not read HOST, ALLOW_LOCAL_ONLY, or Redis environment variables. Local-only mode is a command-line flag (--localhost-only), not an ALLOW_LOCAL_ONLY environment variable.
