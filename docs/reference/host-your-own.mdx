# Host Your Own ErikrafT Drop™

This guide covers the current Docker and Node.js deployment paths. The detailed repository guide is available in [docs/host-your-own.md](https://github.com/erikraft/Drop/blob/master/docs/host-your-own.md).

## Requirements

- Docker Engine and Docker Compose, or Node.js >=22.12.0.
- HTTPS/WSS through a trusted reverse proxy for public deployments.
- A TURN server only when WebRTC connectivity requires it.

## Docker

Clone the repository, build the root Dockerfile and bind the application to localhost behind a reverse proxy:

    git clone https://github.com/erikraft/Drop.git
    cd Drop
    docker build --pull -t erikraft-drop .
    docker run -d --name erikraft-drop --restart unless-stopped -p 127.0.0.1:3000:3000 -e NODE_ENV=production -e RATE_LIMIT=1 -e WS_FALLBACK=false erikraft-drop

For one trusted reverse proxy, RATE_LIMIT=1 is the starting point. Confirm the actual proxy hop count.

## Node.js

    git clone https://github.com/erikraft/Drop.git
    cd Drop
    npm ci
    NODE_ENV=production RATE_LIMIT=1 WS_FALLBACK=false npm start

The default port is 3000. Override it with PORT.

## Production settings

- Set RATE_LIMIT to the correct trusted proxy hop count. It enables the HTTP limiter at 1,000 requests per IP per five minutes.
- WS_FALLBACK is enabled by default. Set WS_FALLBACK=false if the server must not relay file payloads.
- Set WS_ALLOWED_ORIGINS to an explicit comma-separated list of browser origins when you need a fixed allowlist.
- Keep DEBUG_MODE=false.
- Keep the origin inaccessible directly where possible, and ensure the reverse proxy overwrites forwarding headers.
- Use short-lived TURN credentials because RTC_CONFIG is sent to connected clients.

## Transfer paths

WebRTC DataChannels are encrypted between peers. TURN may relay encrypted WebRTC packets. WebSocket fallback sends chunks through the server, which can process the payload. Disable fallback if that trust model is not acceptable.

## Health checks

Use GET /health for a basic health check and /api/v1/capabilities for public API capability metadata.
