<Update label="Nov 2026" description="v10.1.10 (Web)">

  - Added a public API v1 endpoint to retrieve available API capabilities
  - Added RGB rainbow text selection throughout the interface
  - Added portable Windows executables for Wine and Winlator compatibility
  - Introduced Liquid Glass styling to the BioDrop website About page

  ### 🛠 Improvements

  - Improved Desktop receiving dialogs, RBM Convert, and BioDrop
  - Improved compatibility with Linux, Windows, Wine, and Winlator
  - Updated dependencies and improved build and packaging workflows
  - Improved WebSocket connection management and resource handling
  - Improved Cloudflare failover target selection
  - Updated ErikrafT AI™ promotional content across all supported languages
  - Fixed Linux `.deb` packaging and icon issues

  ### 🔐 Security

  - Fixed WebSocket room isolation and introduced limits for untrusted messages
  - Configured the Drop Node.js process to run without root privileges
  - Added baseline HTTP security headers
  - Fixed HTML injection in IP-based room chat messages
  - Improved six-digit device pairing and connection-key validation
  - Added resource limits for incoming Discord bot transfers
  - Improved redaction of sensitive information from runtime and debug logs
  - Enabled HTTP rate limits on Render
  - Added protection against repeated public room creation
  - Improved handling of uncaught server errors
  - Addressed CodeQL media sanitization findings

  ### ⚙️ Infrastructure

  - Improved Discord bot transfer handling and attachment downloads
  - Updated Node.js and project dependencies
  - Fixed CI/CD workflow, cache, and packaging issues
  - Disabled Renovate while retaining Dependabot

  - Added native QR Code scanning and animated QR Code receiving
  - Introduced translucent Liquid Glass styling across the Android toolbar, menus, and dialogs

  ### 📡 File Transfer

  - Improved FTP/FTPS and SFTP server configuration and access controls
